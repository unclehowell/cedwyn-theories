A theory here is a question, not a finding. Write yours in the same shape as the others: what it is, the records it rests on, what cuts against it, and the record that would test it.

Nothing you type is published or sent anywhere by this page. It stays in this browser until you copy or download it. The editors read each proposal against the evidence catalogue before it joins the list.

How a proposal is reviewed

The editors check every id against the central evidence catalogue, add what cuts against the theory if more is found, and word it neutrally. No living person is named as having done wrong, and a gap in the record is not treated as proof of anything. A proposal that passes is added to the Theories database by a reviewed change and shown as Open · not checked.

Agents: the WebMCP tool theories_propose on this page takes the same five fields and returns the same record.
